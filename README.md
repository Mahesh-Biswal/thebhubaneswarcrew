# 🎙️ The Bhubaneswar Crew

> **Voices That Inspire. Stories That Connect.**  
> A premium creative podcast & entertainment community platform from the heart of Bhubaneswar, Odisha.

---

## 🌟 Overview

**The Bhubaneswar Crew** is an online platform celebrating local creators, podcasts, stand-up comedy open mics, inspirational quotes, poetry/shayari, and authentic regional storytelling. Designed with state-of-the-art web aesthetics, deep dark mode, glassmorphic UI elements, and vibrant electric cyan/blue gradients.

- **Founder**: [Suman Sourav Das](https://www.instagram.com/suman_sourav_das)
- **Website**: [thebhubaneswarcrew.in](https://www.thebhubaneswarcrew.in/)
- **Location**: Bhubaneswar, Odisha, India ([Google Maps Link](https://maps.app.goo.gl/BLd8zX1RDRyEnMKo7))

---

## ✨ Features & Highlights

- **Aesthetic Light Blue / Electric Cyan Theme**: Modern dark background (`#060B13`) paired with cyan (`#00D2FF`) and blue (`#3B82F6`) gradients.
- **Interactive Particle Canvas**: Ambient drifting particle animation network that responds dynamically to mouse pointer interactions.
- **Circular App Logo & Favicons**: Multi-resolution favicon support (`favicon.ico`, 16x16, 32x32, 180x180 Apple Touch Icon) with round brand mark integration across navigation bars.
- **High Contrast & Accessible Footer**: Clear contrast typography, glowing social link circles, clickable map links, and a dedicated **Founder Badge** linking to Suman Sourav Das's Instagram profile.
- **Interactive Google Maps Embed**: Embedded location map section and quick links to Bhubaneswar's location on Google Maps.
- **SEO & Social Optimization**: Built-in Open Graph (OG) meta tags, Twitter Cards, Semantic HTML5 hierarchy, and Schema.org Structured Data (JSON-LD).
- **Responsive Layout**: Mobile-optimized navigation menu with smooth drawer transitions and responsive Bootstrap 5 grid scaffolding.

## 🚀 Getting Started Locally

1. **Clone or Download the Repository**:
   ```bash
   git clone https://github.com/Mahesh-Biswal/thebhubaneswarcrew.git
   cd thebhubaneswarcrew
   ```

2. **Run a Local Web Server**:
   You can open `index.html` directly in any web browser, or launch a lightweight HTTP server (e.g., using VS Code Live Server or Python):
   ```bash
   # Python 3
   python -m http.server 8000
   ```
   Then open `http://localhost:8000` in your browser.
